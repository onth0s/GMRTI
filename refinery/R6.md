**R6 — The Primitive Covenant Transmission Problem**
`[OPEN]`

The Minimal Intelligibility Bootstrap (2e.5) stratifies the
decoding substrate into a framework-independent Minimal
Substrate and a GMRTI-specific Primitive Covenant. The
Minimal Substrate is assumed to be universally available
for any structured communication.

The Primitive Covenant, however, contains GMRTI-specific
content: the eight primitive relational operators, the
edge-primacy commitment, and the Tier 1 coarse taxonomy.
Establishing this shared substrate between agents who do
not already possess it is itself a transmission problem —
precisely the kind of problem the GMRTI is designed to
solve, creating a bootstrapping circularity.

**Open questions:** Can the Primitive Covenant be
transmitted using only the Minimal Substrate? If so, what
is the minimum Polyphonic Encoding required? Does the
Primitive Covenant need to be transmitted in full before
any GMRTI-mediated communication can begin, or can it be
established incrementally via JIT-OM as needed? Is the
circularity resolvable, or is it a structural boundary
condition analogous to the Metaagnostic Trap?
