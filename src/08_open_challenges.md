## SECTION 8 — Known Gaps and Open Challenges

**8a — Resolved Across Prior Iterations** `[STABLE]`

**8a.1** *The Node Substantialism Problem* (v0.2): Resolved via edge-primacy
architecture. Nodes are emergent edge-cluster densities, not semantic atoms.

**8a.2** *The Missing Node Contradiction* (v0.2): Resolved. "Missing Nodes"
reclassified as Anchor-Only Subgraphs, consistent with edge-primacy.

**8a.3** *The Metalanguage Trap* (v0.2): Bounded. JIT-OM halts the regress at the
content level; the Content–Protocol Stratification (3e.1vi) explicitly
declares the meta-level. The metaagnostic circularity of the framework's own
foundational posture is a structural boundary condition analogous to Gödelian
incompleteness — describable but not transcendable from within. This is a
proven boundary, not an open challenge. `[STABLE]`

**8a.4** *The Comosí Depth Metric* (v0.2): Addressed via Operational Action
Threshold. Sufficient for practical purposes; does not claim to fully resolve
the philosophical question of comosí depth.

**8a.5** *The Charitable Reading Calibration Problem* (v0.3): Addressed via
Domain Risk Coefficient. See 8b.11 for DRC conflict resolution.

**8a.6** *The Community Covenant Problem* (v0.3): Addressed via Federated Graph
and Artifact Anchor model.

**8a.7** *The Edge-Grounding Regress* (v0.4): Resolved via field-primacy model
(2a.4). Edges are primitive; nodes are emergent density labels.

**8a.8** *The Compiler Metaphor Overreach* (v0.4): Resolved. Compiler metaphor
demoted to mnemonic tool; Isolation Axiom demoted to useful approximation.

**8a.9** *The Undifferentiated Edge Problem* (v0.6): Addressed via Edge Taxonomy
(2a.5) and Edge-Type Misattribution subtype (2c.3).

**8a.10** *The Binary Termination Problem* (v0.6): Addressed via Cost-Bounded
Termination (3a.1iii) and Stopping Principle (3g). The framework now has three
named termination conditions rather than two.

**8b — Addressed, Pending Validation** `[PROVISIONAL]`

**8b.11** *The DRC Classification Problem* (v0.9): Resolved via **Meta-DRC
Alignment** (3c.2, 3e.1v). DRC disagreement is treated as a Meta-DRC Divergence,
triggering negotiation or defaulting to the highest demanded DRC. `[NEW]`

**8b.12** *The Bad Actor Problem* (v0.9): Resolved via the **Topological
Consistency Audit**. A party's claims are checked for internal consistency: if
they introduce contradictions or reject a repair topologically isomorphic to
their own previous claims, a Bad Actor flag is raised. `[NEW]`

**8b.13** *Artifact Anchor Decay* (v0.9): Resolved via the **Periodic
Re-Mirroring Protocol**. The Federated Graph is periodically evaluated against
the Artifact Anchor under the Mirror posture (suspending charity), logging
desynchronization as a Delta Graph. `[NEW]`

**8b.14** *The Redundancy-Masking Detection Problem* (v0.9): Resolved via
**Path-Stripping Probing**. The transmitter temporarily disables all but one
encoding path, forcing the receiver to reconstruct using only that path,
surfacing hidden voids. `[NEW]`

**8b.15** *The Structural Integrity Metric* (v0.9): Addressed via Proxy. The
theoretical metric \(H_s(S) = \log_2 |\{G_R\}|\) is retained as a stable
definition. Direct computation of \(|G_R|\) is constrained by metaagnosticism
and combinatorial complexity. The Behavioral Convergence Proxy (Path-Count
Metric) operationalizes the concept without claiming to compute the theoretical
value. `[NEW]`

**8b.16** *The Axiomatic Visibility Problem* (v0.9): Resolved via the
**Dependency-Tracing Scan**. The topological graph is scanned to identify and
flag edge-clusters whose modification propagates changes downstream beyond a 30%
node threshold. `[NEW]`

**8b.17** *The Edge-Type Balance Problem* (v0.9): Resolved via the **two-tiered
Edge Taxonomy** switching rules (2a.5) that optimize cognitive overhead vs.
diagnostic precision. `[NEW]`

**8b.18** *The Holism Implosion* (v0.9): Resolved via **Boundary-Tracing
Encapsulation** (2h, 3e.1ii), which wraps localized repairs in a
boundary-covenant to attenuate propagation of meaning shifts. `[NEW]`

**8b.19** *The Pathological Mirror* (v0.9): Addressed, conditional on shared
Primitive Covenant. The Minimal Intelligibility Bootstrap (2e.5) stratifies
the decoding substrate into a framework-independent Minimal Substrate and a
GMRTI-specific Primitive Covenant. The Minimal Substrate resolves the
pathological mirror for *any* structured communication; the sharing of the
Primitive Covenant is itself a transmission problem that MIB acknowledges but
does not solve. `[NEW]`

**8b.20** *The Metadata Regress* (v0.9): Addressed via Content–Protocol
Stratification. The eight primitive operators halt regress at the content
level. Protocol-level operations (propose, accept, reject, pause, resume,
default) are declared at a single finite meta-level above content (3e.1vi).
No further meta-level is required. `[NEW]`

**8b.21** *Polyphonic Complexity Drift* (v0.9): Resolved via **Core Path
Minimization** (2f.6) which limits redundant paths to direct translations of a
single canonical path. `[NEW]`

**8b.22** *The Centerless Trap* (v0.9): Managed, pending convergence proof.
Dynamic Re-Anchoring (2d.2) models textual drift as a managed trajectory.
Convergence to stable anchors is guaranteed only if the correction stream
diminishes; no formal proof of convergence or bounded oscillation is yet
provided. The Maintenance Covenant manages the residual but its own stability
depends circularly on Artifact Anchors. `[NEW]`

**8c — Open Challenges** `[OPEN]`

**8c.1** *The Undetected Comosí Ceiling*: JIT-OM and Polyphonic Encoding
address detected divergence and proactively reduce transmission risk.
Neither eliminates the possibility of undetected axiomatic divergence
persisting beneath a functioning comosí. No current mechanism within the
GMRTI can surface a divergence that both parties' covenants are
successfully routing around. This is a structural limitation, not a
solvable problem within the framework's current architecture.

**8c.2** *The Primitive Covenant Transmission Problem*: Establishing the
Primitive Covenant (2e.5ii) between agents who do not already share it is
itself a transmission problem. No Covenant Zero Protocol for bootstrapping
the Primitive Covenant from the Minimal Substrate currently exists.

**8c.3** *The Compiling Overhead Problem*: balancing the friction of
Rationally Agnostic reconstruction against the need for generative creative
flow. High-DRC disciplines can absorb this overhead; the framework's
applicability to lower-DRC creative and philosophical work without
prohibitive cost remains an ongoing optimization target.

**8c.4** *The Convergence Proof Gap*: Dynamic Re-Anchoring (2d.2) and the
Maintenance Covenant (2d.2) lack formal convergence guarantees. A proof that
anchor oscillation remains bounded under specified correction-stream conditions
is needed.

**8c.5** *The Cognitive Overhead Reflexivity Problem*: GMRTI criticizes
existing approaches for cognitive overhead (R2 Refinery) while its own
operational surface — 8 operators, 5-stage algorithm, JIT-OM, PSP, BTE,
DRC, Meta-DRC, polyphonic encoding, Core Path Minimization, Dynamic
Re-Anchoring, Temporal Stranger Protocol — is at least as complex.
Empirical validation that Self-Annotation is cognitively tractable is
needed before the framework's overhead critique can be sustained
without tu quoque.
