# GMRTI Decision Log: Refinement Marching Orders

This log defines the precise resolutions to be implemented in the treatise to
resolve all open contentions.

---

## 1. Resolution of Target Use Case & Developmental Ordering (R3)
- **Decision:** Establish **Self-Annotation (Self-to-Future-Self transmission)**
as the definitive target use case for the first implementation (v0.9).
- **Action:** Update Section 1c, Section 3, and Section 8a/8b/8c to codify that
self-annotation serves as the bootstrapping sandbox, generating conceptual
primitives that Constitutional Drafting formalizes and GMRTI-Mediated Dialogue
simplifies.

## 2. Resolution of Syntactic Edge-Forcing & Operator Prototype (R2)
- **Decision:** Adopt the Concatenation Insight as a mandatory prototype for key
structural claims using primary relational operators.
- **Action:** Define the primitive operator set (`->inferential`, `->causal`,
`->procedural`, etc.). Update Section 2g to show concrete examples of how `A
[->causal] B` forces edge-type traversal, and apply these operators to the key
stable claims in GMRTI itself.

## 3. Resolution of Ontological Type Partition & Markers (R1)
- **Decision:** Formalize the "carved vs. constructed" binary as the
foundational partition for JIT-OM repair.
- **Action:** Update Section 5a to define:
  - ved concepts*: Repaired by worldly reference, logical proof, or empirical
alignment.
  - structed concepts*: Repaired by covenant renegotiation.
  - ndary concepts (e.g. math)*: Defined as
constructed-but-operationally-carved.

## 4. Resolution of Edge Taxonomy Economy (R5 / 8c.6)
- **Decision:** Codify the two-tiered Edge Taxonomy.
- **Action:** Update Section 2a.5 and Section 3e to formalize the boundary and
switching rules: Tier 1 (Causal/Inferential/Other) for initial Covenant
Declaration; Tier 2 (full 8-type taxonomy) triggered locally during Stage 3 for
Edge-Type Misattribution repair.

## 5. Resolution of Meta-DRC Alignment (R7 / 8b.1)
- **Decision:** Integrate Meta-DRC Divergence detection and repair into the core
algorithm.
- **Action:** Update Section 3c (DRC) and Section 3e (Repair) to specify that if
parties disagree on domain risk, it is flagged as a Meta-DRC Divergence.
Communication is paused, and the protocol defaults to the highest demanded DRC
until consensus is negotiated.

## 6. Resolution of Semantic Entropy Metric (R4 / 8c.4)
- **Decision:** Define a formal, quantitative Semantic Entropy Metric.
- **Action:** Update Section 1a.6, Section 2b, and Section 8 to define the
metric \(H_s\) as the count of non-isomorphic receiving edge-configurations
compatible with the surface signal. Operationalize this via the **Behavioral
Convergence Proxy**: the number of independent Polyphonic Encoding paths
required to reach the Operational Action Threshold.

## 7. Resolution of Section 8b & 8c Operational Gaps
- **Decision:** Provide concrete protocols for the remaining open challenges.
- **Action:**
  - 2 Bad Actor Detection:* Define the **Topological Consistency Audit**
(detecting self-contradictory claims or rejection of isomorphic repairs).
  - 3 Artifact Anchor Decay:* Define the **Periodic Re-Mirroring Protocol**
(differential graph comparison against the anchor).
  - 2 Redundancy-Masking:* Define **Path-Stripping Probing** (temporarily
disabling paths to check for local voids).
  - 5 Axiomatic Visibility:* Define the **Dependency-Tracing Scan** (flagging
clusters with high downstream propagation impact).
